# 演示说明与真实截图

## 约3分钟演示（候选人须亲自练习）

1. 打开`preview.html`或本地HTTP服务。说明这是AI辅助开发的原型，公开核心逻辑为规则。
2. 加载演示数据，明确是虚构：8题次、7道首答、4题首答正确，显示57%，4道到期。若已有记录会提示替换，确认前先确认可丢弃。
3. 查看知识点：首答正确率与覆盖分开；增长率当前待纠正为0，因为错误题g2已复测答对。说明历史首答不被覆盖。
4. 点击「去做针对性练习」，初始演示推荐容斥交集题s2。解释当前未纠正数与覆盖缺口。选择A后提交，显示错答、正确选项B与预写解析。
5. 自评「概念不清」，可选择「仍不清楚」。说明只是自评和静态建议，尚无AI错因识别或远程采集。
6. 打开复习，s2尚未到期但可立即纠正，列表不重复。复测选B后，首答正确率仍为50%（4/8），当前错题状态已改变。
7. 返回总览并刷新检查记录。最后在仅演示数据环境里重置；取消不清空，确认后清空。
8. 打开产品方案，说明用户验证、模型评测和正式部署尚未完成。不要现场输入或展示API Key。

用户走不同顺序或跨日后，到期数可能变化；以上初始数字来自新加载的演示样本，不是用户运营指标。

# 版本规划

| 版本 | 状态 | 内容/退出条件 |
|---|---|---|
| v0.1 | 用户提供ZIP基线 | 原生前端、12题、规则推荐、固定复习、本地模型接口、6项测试 |
| v0.2 | 当前本地版本 | 修复推荐饥饿、复习混题、记录校验和路径泄漏；证据可视化、自评、真实截图、发布检查；工程结果见验收报告 |
| v0.3 | 待验证计划 | 先做5人任务测试与独立审题，再按发现优化；有同意机制后才做推荐转化测量 |
| 后续可选 | 未承诺实现 | 20–50道授权审题样例与新同构复测；模型解释盲评达标后再试点 |
| 长期设想 | 未实现 | 登录同步、知识追踪与大题库；仅在明确需求、数据量与维护能力支持后考虑 |

本轮没有为作品数量添加聊天、排行榜、积分、复杂图谱或社交。优先级依据是闭环是否可靠、推荐是否清楚、证据是否可信。

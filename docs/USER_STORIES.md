# 用户故事与验收条件

这是设计用的假设用户故事，未经真实访谈验证。场景不代表已经存在用户。

| 用户故事 | 验收条件 | 证据/边界 |
|---|---|---|
| 作为首次体验者，我想无需注册完成第一题 | 总览进入练习；未选禁用提交；提交后显示结果 | 浏览器闭环和空状态测试 |
| 作为学习者，我想知道为什么是这题 | 显示首答覆盖、当前未纠正数、新题/错题/到期状态 | 决策对象复用；人工及自动化核对 |
| 作为答错的人，我想记录自己卡在哪里 | 自评可跳过；选择后有建议；刷新后保留在本次提交中 | 只存本地，未进行用户错因准确性评估 |
| 作为复习者，我想看到本题当前是否还需纠正 | 最近答对移出待纠正；首答不变；下一次时间更新 | 同题纠正和队列完成回归测试 |
| 作为样例体验者，我不希望误把虚构记录当成成绩 | 跨页面持续标注演示模式；重置后去除 | 完整演示测试 |
| 作为隐私敏感的体验者，我想清除记录 | 明确不可撤销确认；取消保留；确认清空；失败警告 | 隔离测试数据中验证，不操作个人记录 |
| 作为手机体验者，我想读完题干并方便操作 | 320/390/768px 无横向溢出；选项触控高度至少44px | 12 种页面宽度组合；非真实 iOS 验证 |
| 作为未配置模型的体验者，我想照常练习 | 明确未启用；预写解析可用；不发送模型请求 | 本地、离线、静态产物测试 |

P0 失败优先修复；P1 自评和模型价值待用户观察后迭代。暂不新增账号、社交或复杂推荐算法。

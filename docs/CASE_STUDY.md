# 90秒产品案例

**AI辅助实现的个人产品原型，尚无用户和教育效果验证。** 个人贡献说明见[CONTRIBUTIONS](CONTRIBUTIONS.md)，不要直接将本页候选决策全部写成独立成果。

## 问题与目标

初始观察：学过理论却在独立练习时混淆方法；答错后仍不清楚下一题该练什么。目标用户假设是完成过一轮基础学习、需要巩固的自学者。问题来自个人学习情境，未通过外部访谈验证。

## 方案与取舍

用12道原创样例跑通「独立提交 → 首答证据 → 可解释选题 → 预写解析与自评 → 复测」。原生JS/CSS结构保留，先验证闭环，不引入账户、大题库和复杂模型。

首答反映首次表现，最近结果反映当前待纠正状态。推荐优先有新题的知识点，并显示记录与排序依据。这样能避免历史错题永久占据优先级，也避免一再做熟题冲高指标。代价是延后同题纠错，因此提供独立复习入口。

模型仅保留可选本地讲解接口。它可能帮助改写难懂解析，但增量价值尚无评测证据；公开版只用预写解析。

## 已验证什么

已对原始版本执行6项规则测试；修复后补充规则、存储、接口及真实浏览器回归，结果见[验收](ACCEPTANCE.md)。截图由隔离浏览器使用虚构记录生成。工程路径可运行不等于产品价值或学习收益已验证。

## 下一步如何决定

先让5位目标学习者完成任务，看是否能独立找到练习、复述推荐依据、区分首答与纠错；若同一环节阻碍2人以上，先改可用性。之后再做内容独立审查、新同构题复测与模型盲评。不预先承诺留存或提分增长。

## 第一阶段：规则与安全修复

原版验证：Node v24.22.1，直接执行 3 个源文件语法检查及 `node --test tests/*.test.mjs`，原有 6/6 通过。环境没有 npm 可执行文件，后续使用等价的 `node scripts/check.mjs`，不能把未执行的 npm 命令写成实际测试命令。

浏览器基线：本机 Edge 通过真实 HTTP 打开开发服务；加载虚构数据得到 8 次作答、7 道首答、57% 首答正确率、4 道到期题；进入针对性练习、选择错误选项、提交后显示预写解析。内置远程浏览器无法连接本机端口，改用本机 Edge。

已修复：

- 原推荐可困在全部做过的弱知识点，造成新题饥饿；先在有新题的知识点内排序。
- 历史首答错误永久影响优先级；改用最近未纠正错误排序，首答统计仍不可覆盖。
- 复习队列为空时会进入普通新题；现在明确返回完成状态。
- 同毫秒作答的最近记录取值错误；按追加顺序解决。
- `localStorage` 可接受未知题号、伪造对错和知识点；按题库、选项和时间校验并派生对错。
- Windows 反斜杠路径导致隐藏文件拦截失效；静态文件改为白名单，并限制真实路径在项目内。
- AI 接口的 JSON null 可触发异常；补充形状、字节长度、同源、类型、并发与频率限制。
- AI 旧请求返回时可覆盖同题的新作答；使用作答轮次隔离。
- 复习和重置时 URL 与界面不一致；修正 hash 更新。
- 存储失败被静默忽略；增加持续提示。

阶段检查：`node scripts/check.mjs` **21/21 通过**；`node scripts/build-preview.mjs` 成功。新增测试涵盖新题饥饿、纠错优先级、复习完成、存储损坏、Windows 路径和模型接口失败。模型测试使用替身，未调用真实模型。

本阶段剩余：完整新版浏览器闭环、移动端、离线版、静态子路径与发布产物将在后续阶段继续验收；真实模型效果及公网 Pages 尚未验证。

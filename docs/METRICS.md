# 指标字典与目标（均无真实用户结果）

## 已有本地事实与尚未实现测量

| 指标 | 口径 | 实现/限制 |
|---|---|---|
| 累计作答 | 每次成功提交为一题次 | 已展示，含复测 |
| 首答正确率 | 每题最早一次提交正确数 / 已首答题数 | 已展示；复测不覆盖；空数据为「—」 |
| 题库覆盖 | 不同已首答题数 / 12 | 已展示；不是掌握度 |
| 当前待纠正 | 每题最近一次提交为错的题数 | 已在知识点与复习中展示 |
| 同题纠正数 | 首答错且最近一次答对的题数 | 已展示；不是学习增益，存在记忆效应 |
| 自评与解析反馈 | 本次提交附加枚举标签，可修改 | 已本地保存；无汇总统计或远程分析 |
| 推荐开始/完成率 | 关联一次推荐曝光、开始与提交 | 未埋点，不能计算 |
| 延迟迁移正确率 | 固定3–7天窗口，新同构题正确数 / 有效复测题数 | 未实现新题评测与招募，不可用当前同题纠正数替代 |

首答和复测的分母必须分开；演示模式全部排除在真实效果分析外。失败保存的内存记录不应计入后续持久数据分析。同一会话反复刷新产生的曝光也不应重复计入。

## 候选验收目标与验证方法

这些是下一轮预先设定的产品判断标准，不是已达成结果。

- 5位测试者中至少4位，无解释在60秒内找到练习并提交一题。
- 至少4位能用自己的话说明推荐与错题/覆盖的关系，并知道它是规则。
- 至少4位能找到复习与重置，理解虚构数据和本地存储边界。
- 若出现2人以上同处受阻，先修可用性，不扩题、不加模型功能。

样本5人只能发现交互问题，不能推断人群转化、留存或提分。对照实验需先完成题目难度校准、获得同意并制定样本量方案，不承诺某百分比增长。
